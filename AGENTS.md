# OTF Exercises iOS Agent Notes

This repository is a native SwiftUI iOS migration of the read-only web reference app in `reference/OTf-exercises`.

## Guardrails

- Treat `reference/OTf-exercises` as read-only source material. Do not modify, commit, push, or open PRs against it.
- Keep `reference/` ignored by git.
- Preserve real exercise data and media references from the web app; do not add fake records.
- Use SwiftUI-native interaction patterns instead of wrapping the website in a web view.
